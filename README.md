# 2D_Game.js

This is a 2d game created in the game engine developed in class.
<br>
The objective in this game is to move the ship at the bottom of the screen, you must collect as many stars as you can while avoiding the asteroids. Every 15 seconds the difficulty increases meaning stars are less likely to spawn and asteroids become more likely to spawn. 
<br>
The game ends once you lose all 3 lives.

### controls:
press 'space' to start the game<br>
use the arrow keys to move from left to right<br>
press 'esc' to pause/unpause the game<br>
